# Balance-equivalence evidence

Statistical evidence that the determinism jar does not meaningfully change worldgen frequencies —
the supporting material for upstream adoption and for the speedrun community's own review.

## Method

Two arms, identical seed lists, cold runs (fresh JVM per world) against the stock GTNH 2.7.4
server pack: **stock** (no jar) vs **fixed** (determinism jar). Each run generates the
spawn-centered radius-15 window (961 chunks) and records every chest inventory, GT ore tile
entity, village piece list, and witchery structure (probe `search=true` reports; raw JSONs are
archived out-of-repo in `results/` because of size — ask if you want the corpus).

Rates are compared as fixed/stock ratios against a ±10% equivalence bound. The verdict CI is a
**seed-paired, region-clustered bootstrap** (4,000 replicates; seeds resample as units, so chests
inside one world are never treated as independent draws and the arms stay paired). `PASS` = 95%
CI inside the bound. `FAIL` requires the 99.9% CI entirely outside it; at that threshold the
expected number of false FAILs across all ~550 rows is ~0.6 (stated in each report header). The
older analytic draw-based CI is retained as a comparison column — it ignores clustering and
overstates certainty for items concentrated in few regions (e.g. dungeon loot).

`inconclusive` means the sample cannot bound the difference at ±10% — mostly rare items. Those
are covered by the direct-code Monte-Carlo tier instead: `roguelike-loot-mc.json` holds 500,000
draws per loot category/level made by calling the *shipped* Roguelike loot-table code via
reflection, certifying rare-item table probabilities to sub-percent precision (the jar provably
does not modify table code — its mixins only substitute the Random instance).

## Reports

- `balance-report-bootstrap-oldfixedarm.md` — the 60-seed corpus (120 regions/arm) under the
  bootstrap methodology. **Fixed arm = the pre-release 0.4pre jar**; kept for methodology
  comparison. Headline: 2 FAIL rows of 550 (two rare Tinkers part items in chests, suspected
  artifacts of the old jar's loot path, superseded by the release jar); the previously reported
  fireworks and Alunite deltas do not survive clustering — both were between-seed lottery
  variance, not stable rate shifts.
- `balance-report-0.4.md` *(pending)* — the release-jar fixed arm on the instrument-clean
  50-seed subset; the authoritative document for upstream PRs.
